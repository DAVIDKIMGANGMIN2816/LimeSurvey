# God Three Kingdoms Game Survey Example

This directory contains an example survey template for collecting user feedback about the "갓삼국" (God Three Kingdoms) mobile RPG game.

## About the Game

갓삼국 (God Three Kingdoms) is a Korean mobile RPG featuring:
- Mass siege battles with thousands of simultaneous players
- Unlimited character gacha system
- Server-wide alliance tournaments
- Open-world Three Kingdoms map

## Survey Purpose

This example survey demonstrates how LimeSurvey can be used to:
1. Collect player feedback on game features
2. Assess user satisfaction with game events
3. Verify user understanding of app permissions
4. Gather suggestions for improvements

## App Permissions Covered

The survey includes questions about Android app permissions:

### Storage Permission
- Guest user platform access
- File attachment uploads
- Photo downloads from the game

### Camera Permission  
- Photo uploads through the game lounge

### Microphone Permission
- Voice chat functionality in the app

## Permission Management

**For Android 6.0 and above**: 
Settings > Application Manager > Select App > Permissions > Revoke access

**For Android below 6.0**: 
Permission revocation not supported; must uninstall app to revoke

## Files

- **god-three-kingdoms-survey.lss**: A complete LimeSurvey template file in Korean that can be imported into LimeSurvey

This example demonstrates:
- Korean language survey implementation
- Multi-group question structure
- Various question types (List, Multiple choice, Yes/No, Text)
- Help text for providing additional context
- Integration of game features into survey questions

## Usage

To use this survey template:
1. Open your LimeSurvey admin panel
2. Go to "Create survey" or "Import survey"
3. Select the `god-three-kingdoms-survey.lss` file
4. The survey will be imported with all questions and settings in Korean

This serves as a reference for creating surveys in Korean for mobile game user research.
